# Acceptance Gates Matrix

Date: 2026-07-10

## Gate Strategy

Creator Pivot V2 cleanup gates have two phases:

1. **Classification phase**: legacy residue is allowed only when it is inventoried and owned.
2. **Deletion phase**: after V2 replacements ship, the same gates are tightened to reject the old residue entirely.

This prevents a false clean-room rewrite while still stopping uncontrolled legacy creep.
