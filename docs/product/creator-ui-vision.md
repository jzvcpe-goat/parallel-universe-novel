# Creator UI Vision

Creator is a professional, local-first author workbench driven by reader demand.

The core flow is:

1. Readers ask for the next chapter or a branch.
2. The author sees what matters today.
3. The author writes or edits privately.
4. The author chooses the destination line.
5. The author confirms publication.
6. Reader Web shows the new chapter or branch.

Creator must feel operational and focused, not like a concept-art dashboard. It uses a dark professional workbench, restrained liquid glass controls, and a quiet writing surface.

## P0 Boundaries

- No cloud writing runtime.
- No hosted author credential.
- No automatic publishing.
- No generated prose stored remotely before confirmation.
- No Reader visual background assets.
- No engineering copy in product UI.

## Six Primary Entrypoints

1. 今日
2. 读者请求
3. 写作台
4. 作品与支线
5. 发布检查
6. 创作设置
