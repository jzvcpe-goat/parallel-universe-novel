# Accessibility

Creator must remain usable from keyboard and assistive technology.

Requirements:

- Use Radix-backed shadcn controls for dialogs, selects, tabs, sheets, and tooltips.
- Every input needs a visible label or accessible label.
- Every destructive action uses a confirmation dialog.
- Disabled actions explain why they are disabled.
- Reduced transparency must keep contrast readable.
- Editor and preview areas must not use strong glass backgrounds.
- Generated writing candidates must be named review regions with polite live updates, so keyboard and assistive-technology users can perceive that a new candidate entered review.
