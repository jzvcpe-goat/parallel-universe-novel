# Liquid Glass

Liquid Glass is a control-layer treatment, not a page background.

Allowed:

- Navigation surfaces
- Request cards
- Publish check panels
- Right rails
- Confirmation dialogs
- Small status cards

Not allowed:

- Long-form editor body
- Chapter preview body
- Full Creator page background
- Reader planet imagery inside Creator

Use `app/src/components/ui/liquid-glass.tsx` and semantic Creator tokens.
